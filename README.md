## 🌟 최신 신규 추가 기능 (v5.0 Update)

### 1. 🎛️ Lo-Fi Vintage FX Rack (아날로그 빈티지 이펙터 체인)
- **Muffled Room Lowpass Filter (옆방 / 룸 먹먹함 필터)**:
  - BiquadFilterNode를 활용하여 마치 문 닫힌 옆방이나 비 내리는 차 안에서 음악을 듣는 듯한 아늑하고 먹먹한 사운드를 연출합니다 (컷오프 주파수 조절 가능).
- **Cassette Wow & Flutter (카세트 테이프 피치 흔들림)**:
  - LFO와 DelayNode 기반의 미세 피치 변조로 오래된 아날로그 테이프가 늘어질 때 나는 아련한 요동 효과를 재현합니다.
- **Tape Warmth Saturation (진공관/자성 테이프 포화도)**:
  - WaveShaperNode를 통한 비선형 배음 왜곡으로 소리를 한층 더 따뜻하고 풍성하게 감싸줍니다.
- **Vinyl Dust & Crackle (LP 먼지 잡음)**:
  - 바늘이 디스크를 긁으며 발생하는 특유의 지지직거리는 먼지 잡음 볼륨 조절.

### 2. ⌨️ 실시간 키보드 타이핑 ASMR (Keyboard Typing Sound)
- **코딩/글쓰기 몰입 극대화**: 웹페이지 내에서 키보드를 칠 때마다 실시간으로 쫀득한 타건 사운드가 합성되어 울려 퍼집니다.
- **2가지 스위치 모드 제공**:
  - **기계식 키보드 (Mechanical Clicky / Thock)**: 경쾌한 클릭 틱 + 묵직한 하우징 바닥 충격음 (스페이스바/엔터 전용 톤 지원).
  - **빈티지 타자기 (Vintage Typewriter & Bell)**: 찰칵거리는 금속 활자 타건음과 엔터 입력 시 청아한 줄바꿈 딩!(Bell) 차임벨.

### 3. 🐱 아늑한 픽셀 룸 스튜디오 씬 (Cozy Pixel Room Scene)
- **중앙 센터피스 탭 전환 (`📻 TURNTABLE` vs `🐱 PIXEL ROOM`)**:
  - 100% 로컬 Canvas 도트 렌더러 기반의 감성 픽셀 일러스트 룸 뷰 제공.
  - **실시간 날씨 & 시간대 연동**: 실제 시각(새벽, 낮, 노을, 심야)에 따라 창밖 하늘색과 초승달, 별빛, 구름이 변하며, 빗소리가 켜지면 창밖에 픽셀 빗방울이 내립니다.
  - **살아 숨쉬는 디테일**: 책상 위 커피 머그잔의 모락모락 김 피어오름, 창가 방석에서 숨 쉬며 잠자는 치즈 태비 고양이의 들숨날숨과 꼬리 흔들림.
  - **고양이 인터랙션**: 고양이를 클릭하면 귀여운 픽셀 하트(❤️)가 퐁퐁 솟아오릅니다.

### 4. 📊 4가지 멀티모드 오디오 비주얼라이저 (Multi-Mode Visualizer)
- 헤더의 **`[📊 VISUAL]`** 버튼 클릭 한 번으로 실시간 모드 순환 전환:
  - **`RING`**: 몽환적인 네온 원형 스펙트럼 리플 & 펄스 코어
  - **`VU`**: 클래식 카세트 데크 좌/우 듀얼 아날로그 바늘 미터 (VU Meter)
  - **`WAVE`**: 유려한 네온 오실로스코프 타임도메인 파형선
  - **`BARS`**: 36밴드 사이버펑크 네온 이퀄라이저 바 & 피크 홀드 애니메이션

## 🎧 기존 핵심 기능 요약 (v4.0 Spatial Edition)
- **3D 공간 음향 원룸 배치 (`3D ROOM` 버튼)**: 2D 평면도에서 나(ME)를 기준으로 6개 사운드를 드래그 앤 드롭하여 HRTF 입체 서라운드 사운드 구현.
- **시간대별 무드 조명 (`Auto Time Sync`)**: 새벽, 낮, 노을, 심야 자동 감지 및 배경 조명/네온 테마 동기화.
- **6채널 독립 사운드 신시사이저**: 빗소리, 카페 소음, 장작불, 밤바다 파도, 집중/수면 바이노럴 비트, 재즈 로파이 비트.
- **집중 & 수면 관리**: 528Hz 싱잉볼 차임벨 뽀모도로 타이머(25m), 마지막 3분 지수 감쇠 수면 슬립 타이머, `F` 키로 켜는 Zen Focus 대형 시계 모드.
